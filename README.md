# TV 回测记录器

TradingView 回测时，在面板上点一下，把这笔的**方向 / 开仓价 / 止损价 / 止盈价 / 截图**复制走，
到 Excel 里 `Ctrl+V` —— 数据成一行，截图跟着一起进来。

也可以直接 **导出 `.xlsx`**：截图会以「嵌入单元格」的形式写进表格（不是浮动图片）。

当前版本 **1.0.0**（商店首发版）。

---

## 安装（一次性）

1. Chrome 地址栏输入 `chrome://extensions/`
2. 打开右上角 **开发者模式**
3. 点 **加载已解压的扩展程序**
4. 选这个目录：`D:\交易学习\TV回测插件\extension`
5. 装好后建议在扩展栏把它**固定**（图钉图标）

装完刷新一下 TradingView 页面。

> **从旧版升级**：在 `chrome://extensions` 点这个扩展的 **↻ 重新加载**，再刷新 TradingView 页面。

---

## 用法

1. 打开 TradingView 图表页（`https://www.tradingview.com/chart/...`）
2. 在图上用 **Long Position / Short Position** 画一个仓位工具（含开仓、止损、止盈）
3. 图表上出现 **「TV 回测记录器」** 面板（默认右上角，**按住标题栏可拖到任何位置**）
4. 点面板里的 **「复制这一笔（含截图）」**
   - 自动截取**当前整屏**（不落盘、不生成文件）
   - 价格 + 截图**一起**进剪贴板
5. 切到 Excel 台账，在最后一行下面 `Ctrl+V` → 一行数据 + 一张图

攒了好几笔没复制？点面板底部 **「复制全部（含截图）」**，一次粘多行 —— **每行都带图**。

### 另一种：直接导出 xlsx

点面板底部的 **「导出 Excel（图片嵌入单元格）」**，浏览器会下载一个 `.xlsx`：

- 14 列固定表头：`时间 · 品种 · 周期 · 方向 · 开仓价 · 止损价 · 止盈价 · 风险 · 回报 · 盈亏比 · 截图 · 备注 · 盈亏 · 胜率`
- 「截图」列里的图片是**嵌入单元格**的（WPS 的 `DISPIMG` 形式），不是浮在表格上的对象
- 所有单元格**水平 + 垂直居中**
- 同一张截图只存一份，多笔共用（文件不臃肿）
- 文件在本机即时生成，不经过任何服务器

> 注意：**粘贴**进 Excel 的图是浮动对象；**导出 xlsx** 的图才是嵌入单元格。
> 想要「图在格子里」就用导出。


复制过的条目会标上 **`✓ 已复制`** 并变绿，按钮变成「再复制一次」，底部计数 `已复制 2 / 5 笔`，
一眼看出还剩哪几笔没导。这个状态**只活在当前页面里，刷新就重置**（不做持久化）。

## 面板说明

| 元素 | 含义 |
|---|---|
| 标题栏 | **按住可拖动面板**，位置会记住，下次打开还在原处 |
| 左上角小圆点 | 绿=读到工具；红=读取失败；灰=没检测到。**点一下 = 复制诊断信息** |
| 多 / 空 徽章 | 多单红、空单绿 |
| `✓ 已校验` | 算出的止损价与图上原始锚点一致，可信 |
| `仅公式` | 只靠公式换算得出（原始锚点里没给），建议肉眼核一下 |
| `✓ 已复制` | 这一笔已经复制走了；整条会变绿，按钮变成「再复制一次」 |
| `已忽略 N 个图上隐藏的工具` | 图上的工具被隐藏了，面板就不会列它 |
| ⟳ | 手动重新读取 |
| − | 收起面板 |
| 底部 `已复制 2 / 5 笔` | 进度；全部复制完显示「已全部复制 N 笔」 |
| 底部「复制全部（含截图）」 | 一次复制面板上所有仓位工具，多行 + 图一起进剪贴板 |

## 输出的列

**复制到剪贴板**是 12 列，Tab 分隔：

```
时间 · 品种 · 周期 · 方向 · 开仓价 · 止损价 · 止盈价 · 风险 · 回报 · 盈亏比 · 截图 · 备注
```

**导出的 xlsx** 是 14 列（多出「盈亏 / 胜率」两个空列给你手填）。

复制时剪贴板里同时放两种格式，粘到哪儿自己挑：

| 粘到哪 | 拿到什么 |
|---|---|
| **Excel / WPS** | HTML 格式 → 表格落位，**图作为浮动对象贴在「截图」列上方** |
| **记事本 / 纯文本** | 一行 TSV，没有图 |

> 「截图」这一列**本身是空的**（不写文件路径），图直接落在格子上。
> 想让它真正**嵌进单元格**，就用面板的「导出 Excel」。


**列顺序要跟你的 Excel 台账对齐**，否则粘贴会错列。
改 `extension/src/shared/columns.js` 里的 `COLUMNS` 数组即可（改完在 `chrome://extensions` 点一下重新加载）。

T1 / T2 / T3、踏空、手数、结果 —— 这些插件**不管**，你在 Excel 里手填。

## MGC 盈亏公式（Excel 侧用）

| 项 | 值 |
|---|---|
| 1 手合约规模 | 10 金衡盎司 |
| 最小变动价位 | 0.10 美元 / 金衡盎司 |
| 每手每 tick 价值 | 1.00 美元 |

```
盈亏(美元) = (出场价 − 入场价) × 10 × 手数      // 多头
```

## 权限说明（为什么它要「读取所有网站的数据」）

`manifest.json` 里申请了 `<all_urls>` 主机权限。这看着吓人，但**必须**：

Chrome 的 `tabs.captureVisibleTab`（截图）硬性要求扩展要么有 `<all_urls>`，要么有 `activeTab`。
而 `activeTab` 只在「用户点扩展图标 / 快捷键 / 右键菜单」时才授予 —— 我们是在**页面内面板上点按钮**，
拿不到 activeTab，所以只能用 `<all_urls>`。

除它之外只申请了 `storage`（存台账）和 `activeTab`，**没有下载权限**（图片不再落盘）。

实际行为上，扩展**只会在 `tradingview.com` 页面上注入脚本**（`content_scripts.matches` 限定的），
数据也**只留在你本机**（`chrome.storage.local`），不外发。

## 已知限制

- **截图只覆盖当前可见视口**，图看不全就先按一下 TradingView 的「适应内容」再复制
- 图片是**浮动对象**，不占单元格；行数多了图会叠在表格右侧，按需删
- **「复制全部」的多行共用同一张图** —— `captureVisibleTab` 同一时刻只能截到一张画面，
  而 TradingView 网页版没开放 `priceToCoordinate` / `timeToCoordinate`（已实测），
  没法按每个工具的屏幕位置裁出各自区域。好在**同屏画的几个仓位，本来就是同一张画面**，语义是对的。
- **截图状态只活在当前页面**：刷新 / 重开 TradingView 后，`✓ 已复制` 会清空（这是刻意的，不做持久化）
- 读的是 TradingView 网页版的内部接口，**TV 大改版后可能需要修**（面板会显示红点提示读不到）
- **图上「隐藏」的工具会被忽略**这条逻辑，用的是多路兜底判定，未能在自动化环境验证（TV 禁止匿名会话画线）；实际走哪条路由圆点诊断报出
- 只在 **WPS 表格**上实测过粘贴，Microsoft Excel 未实测
- 没有在 Bar Replay 回放模式下完整验证过，用的时候留意一下

## 排查

**面板没出现** → `chrome://extensions` 里看有没有报错；确认扩展已启用；刷新页面。

**红点 / 读不到工具** → 确认画的是「Long Position」或「Short Position」（不是普通水平线）；点 ⟳ 重试。

**数字不对** → 看是 `✓ 已校验` 还是 `仅公式`；后者可能是 TV 改了属性结构，把面板上的数字和图上实际价位对一下。

**隐藏了但还显示** → 点左上角小圆点，诊断信息会自动复制到剪贴板，发给小B。

**只有文字进去了、图没跟上** → 粘贴时改用「选择性粘贴 → HTML 格式」；或确认复制时按钮提示的是「已复制 ✓ 含截图」而不是「已复制文字（截图未带上）」。

**复制了但 Excel 没分列** → 粘的时候用「选择性粘贴 → 文本」。
