## 三、详细说明 / Detailed description（限 16000 字符）

```
做交易回测最烦的一步，是"记录"。

画一笔仓位、截一张图、切到 Excel、填一行数字、再把图贴进去……
一笔两笔还行，一天几十笔，人就烦了，最后干脆不记了。

TV 回测记录器把这一步压成"点一下"。

━━━━━━━━━━━━━━━━━━━━━━━━

■ 它是怎么工作的

1. 在 TradingView 图表上，用 Long Position / Short Position 画好你的仓位
   （含开仓、止损、止盈三档价位）。
2. 图表上会出现一个悬浮面板，自动列出图上所有仓位工具，
   并读好：开仓价、止损价、止盈价、风险、回报、盈亏比。
3. 点「复制这一笔（含截图）」——
   全屏截图 + 这一笔的全部数字，一次性进剪贴板。
4. 切到 Excel / WPS，在下一行 Ctrl+V：
   数字落进对应列，截图同时贴上来。继续画下一笔，继续粘。

攒了好几笔没顾上复制？点「复制全部（含截图）」，
面板上所有仓位工具一次全导，多行 + 每行都带图。

━━━━━━━━━━━━━━━━━━━━━━━━

■ 还能直接导出成 Excel 文件

不想手动粘贴？点面板底部的「导出 Excel」，直接下载一个 .xlsx：

· 表头固定：时间 · 品种 · 周期 · 方向 · 开仓价 · 止损价 · 止盈价 · 风险 · 回报 · 盈亏比 · 截图 · 备注 · 盈亏 · 胜率
  （最后两列留空，给你手填结果）
· 截图以"嵌入单元格"的方式写进「截图」列（WPS 的 DISPIMG 形式），
  图片就在格子里，不是飘在表格上的浮动对象，不会乱跑
· 所有单元格水平 + 垂直居中，拿到就能用
· 同一张图只存一份，多笔共用，文件不臃肿
· 文件直接生成在你本地，不经过任何服务器

━━━━━━━━━━━━━━━━━━━━━━━━

■ 面板上你会看到什么

· 悬浮面板，按住标题栏可以拖到任何位置，位置会记住
· 每笔显示方向和三个价位，多头红色、空头绿色
· 「✓ 已校验」= 算出的止损价与图上原始锚点一致，可信
· 「仅公式」= 只靠公式换算得出，建议肉眼核一下
· 复制过的条目会变绿并标上「✓ 已复制」，底部显示"已复制 2 / 5 笔"，
  一眼看出还剩哪几笔没导
· 图上被隐藏的绘图工具会被自动忽略，不会混进列表
· 左上角小圆点：绿=读到工具，红=读取失败，点一下自动把诊断信息复制出来

━━━━━━━━━━━━━━━━━━━━━━━━

■ 关于隐私（重要）

· 不联网：扩展不向任何服务器发送数据，没有分析统计、没有追踪、没有广告
· 不上传：你在图上的价格、截图，全部只留在你自己的电脑里
· 不联网存储：面板位置和本次记录只存在浏览器本地（chrome.storage.local）
· 权限说明：扩展只申请了必要权限。截图能力（captureVisibleTab）在 Chrome 中
  需要「读取所有网站数据」这一权限才能工作，但脚本实际只在 tradingview.com
  页面上运行，其它网站一律不碰

━━━━━━━━━━━━━━━━━━━━━━━━

■ 适合谁

· 用 TradingView 做日内 / 短线回测，需要给每笔留档的交易者
· 想把「图形 + 数字」一次性存进 Excel 台账、方便复盘统计的人
· 已经手动记录到烦、正在找自动化方案的人

━━━━━━━━━━━━━━━━━━━━━━━━

■ 已知限制（如实告知）

· 截图范围是当前可见的图表视口，图看不全时先按一下 TradingView 的
  "适应内容"再复制
· 「复制全部」的多行共用同一张截图 —— 同一屏画的几笔本来就是同一张画面
· 读的是 TradingView 网页版的内部接口，TV 大改版后可能需要更新
  （面板会显示红点提示读不到，不会静默出错）
· 已在 WPS 表格实测；Microsoft Excel 未实测
· 本扩展只是一个"记录工具"，不含任何交易建议、信号或预测

━━━━━━━━━━━━━━━━━━━━━━━━

■ 用法速查

1. 装好后打开 TradingView 图表页（chrome://extensions 里把它固定到工具栏）
2. 在图上画 Long Position / Short Position
3. 面板出现 → 点「复制这一笔（含截图）」
4. 到 Excel 里 Ctrl+V，或点「导出 Excel」

有问题、有建议，欢迎在支持页面留言。
```
