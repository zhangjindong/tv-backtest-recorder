## 1. 单一用途说明 / Single purpose

**直接粘贴：**

```
TV Backtest Recorder records TradingView backtesting trades into Excel.

Its single purpose is to capture the entry / stop / target prices of the Long
Position and Short Position drawing tools on a TradingView chart, together with a
screenshot of the chart, and place that data on the clipboard — or export it as an
.xlsx file — so the user can keep a trade journal. It does nothing else: it does
not analyse markets, generate signals, place orders, or modify the chart.
```

## 2. 权限理由 / Permission justifications

### 2.1 `storage`

```
Used only to store, on the user's own machine, (a) the on-screen position of the
extension's floating panel so it reopens where the user left it, and (b) the list of
trades captured during the current session so the popup can show a count / allow a
re-copy. Data is written to chrome.storage.local only. It is never synced, uploaded,
or shared.
```

### 2.2 `activeTab`

```
Allows the extension to interact with the tab the user is currently viewing when the
user explicitly clicks a control in the extension's popup or on-page panel (for
example to trigger a screenshot or re-read the chart). It is only exercised in
response to a direct user action.
```

### 2.3 主机权限 / Host permission —— `<all_urls>`

> ⚠️ 这是审核最关注的一条。理由必须具体，不要写「为了正常运行」这种空话。

> ✅ **已实测（Chrome 152）**：把 `host_permissions` 收窄成
> `["https://*.tradingview.com/*"]` 后，调用截图会直接报错：
> `Either the '<all_urls>' or 'activeTab' permission is required.`
> 也就是说，**这条权限无法再收窄** —— 引用这个实测结果能让审核更信服。

```
All-sites host access is required for a single technical reason: the extension calls
chrome.tabs.captureVisibleTab() to screenshot the chart. Chrome only grants
captureVisibleTab() to extensions that either hold all-sites host permission or have
received a transient activeTab grant. activeTab is granted only when the user clicks
the extension's toolbar icon, a keyboard shortcut, or a context menu item — but this
extension's screenshot is triggered from a button inside an on-page panel, so no
activeTab grant is ever produced. All-sites host permission is therefore the only way
to make the screenshot work.

This was verified during development: narrowing host_permissions to
https://*.tradingview.com/* makes Chrome reject the capture call with
"Either the '<all_urls>' or 'activeTab' permission is required."

In practice the extension's reach is deliberately narrow:
  * Its content scripts are declared for https://*.tradingview.com/* only. No script
    is injected into any other website, and no other website's DOM is read or modified.
  * The only data it touches is the price values of the user's own drawing tools on
    the TradingView chart, plus the pixel screenshot the user explicitly requested.
  * No page content of any kind is transmitted anywhere — the extension performs zero
    network requests and contains no remote code.
  * It never reads or modifies credentials, form fields, cookies, or browsing history.
```

## 3. 远程代码 / Remote code

**问题：Are you using remote code?**
→ **选 No（否）**

```
No. All JavaScript, CSS and images are bundled inside the extension package. The
extension uses no eval(), no new Function(), no remote script tags, no dynamically
loaded modules, and performs no network requests of any kind.
```
