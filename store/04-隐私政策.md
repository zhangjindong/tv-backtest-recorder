## 中文

### 一句话总结

**本扩展不收集、不存储、不传输你的任何个人数据。** 所有数据只存在于你自己的电脑上。

### 1. 我们收集哪些数据

**不收集任何数据。**

本扩展没有：

- 任何形式的网络请求（无 `fetch`、无 `XMLHttpRequest`、无 `WebSocket`）
- 任何分析统计 SDK（无 Google Analytics、无埋点、无崩溃上报）
- 任何账号系统（不需要登录、不需要邮箱）
- 任何广告或第三方脚本
- 任何形式的远程代码加载（所有代码都打包在扩展内）

### 2. 扩展在本地处理什么

扩展在你浏览器本地处理以下内容，**它们不会离开你的设备**：

| 内容 | 用途 | 存放位置 |
|---|---|---|
| 你在 TradingView 图表上的仓位工具数值（开仓价、止损价、止盈价） | 显示在面板上、生成可复制的文本 | 仅内存，不写入磁盘 |
| 图表截图 | 供你粘贴进 Excel 或导出 xlsx | 仅内存，随用随弃 |
| 悬浮面板的位置 | 下次打开图表时面板停在原处 | `chrome.storage.local`（本机浏览器存储） |
| 本次会话的记录列表 | 弹窗里查看"共 N 笔" | `chrome.storage.local`（本机浏览器存储） |
| 你手写的备注 | 随记录一起导出 | `chrome.storage.local`（本机浏览器存储） |

导出的 `.xlsx` 文件由扩展在你本机即时生成，通过浏览器默认下载流程保存到你选择的目录。

你可以随时在 `chrome://extensions` 中移除本扩展，或在扩展的弹窗里点「清空记录」，即可删除上述全部本地数据。

### 3. 权限用途说明

| 权限 | 为什么需要 |
|---|---|
| `storage` | 保存悬浮面板的位置和本次记录列表到本机（`chrome.storage.local`）。不同步、不上传。 |
| `activeTab` | 当你主动点击扩展的界面元素时，允许扩展与当前标签页交互。 |
| 网站访问权限 | 见下方「关于"读取所有网站数据"」。 |

### 4. 关于「读取所有网站数据」这一权限

安装时 Chrome 会提示本扩展可以「读取和更改你在所有网站上的数据」。这个提示看着吓人，但它是 Chrome 的权限机制导致的**必要之选**：

- 扩展需要调用 `chrome.tabs.captureVisibleTab` 为你截图；
- Chrome 规定，调用该 API 的扩展**必须**持有「对所有网站的访问权限」或临时的 `activeTab` 授权；
- `activeTab` 授权只在你点击扩展图标／快捷键／右键菜单时产生，而本扩展的截图入口是**页面内悬浮面板上的按钮**，触发不到 `activeTab`。

因此只能声明该权限。**但实际行为受到严格限制：**

- 内容脚本的注入范围被限定为 `https://*.tradingview.com/*`，**其它网站一律不注入、不读取、不修改**；
- 扩展在任何情况下都不会把网页内容发送到外部；
- 扩展不会读取或修改你的密码、表单、Cookie 或任何与交易无关的页面数据。

### 5. 第三方

本扩展不向任何第三方共享、出售或转让数据 —— 因为它本身不接触任何数据外发通道。

### 6. 儿童隐私

本扩展不面向儿童，也不收集任何年龄相关信息。

### 7. 政策变更

若未来版本改变了数据处理方式，我们会在扩展的更新说明中明确告知，并同步修订本文件。

### 8. 联系方式

如有疑问，请通过扩展商店页面的支持渠道联系开发者。

## English

### Summary

**This extension does not collect, store, or transmit any personal data.** Everything happens locally on your own computer.

### 1. Data we collect

**None.**

The extension contains:

- No network requests of any kind (no `fetch`, no `XMLHttpRequest`, no `WebSocket`)
- No analytics or telemetry SDK
- No accounts, no login, no email collection
- No ads, no third-party scripts
- No remote code — every line of JavaScript ships inside the package

### 2. What is processed locally

The following is handled entirely on your device and never leaves it:

| Item | Purpose | Where it lives |
|---|---|---|
| Position tool values read from your TradingView chart (entry / stop / target) | Shown in the panel and copied to your clipboard | Memory only |
| Chart screenshot | For pasting into Excel or exporting an xlsx | Memory only, discarded after use |
| Floating panel position | So the panel reopens where you left it | `chrome.storage.local` |
| Current session's record list | Shown as "N trades" in the popup | `chrome.storage.local` |
| Notes you type | Exported with the record | `chrome.storage.local` |

Exported `.xlsx` files are generated locally in your browser and saved through the
browser's normal download flow to the folder you choose.

Removing the extension or clicking "clear records" in the popup deletes all of the
above local data.

### 3. Permission justification

| Permission | Why |
|---|---|
| `storage` | Saves the panel position and the session's record list locally. Never synced or uploaded. |
| `activeTab` | Lets the extension interact with the current tab when you explicitly click its UI. |
| Host access | See below. |

### 4. About the "read data on all websites" permission

Chrome warns that the extension can read and change data on all websites. This is a
consequence of Chrome's permission model, not of what the extension actually does:

- The extension calls `chrome.tabs.captureVisibleTab` to capture a screenshot.
- Chrome requires that API's caller to hold either all-sites host access or a
  transient `activeTab` grant.
- `activeTab` is only granted by clicking the extension icon, a keyboard shortcut,
  or the context menu. This extension's trigger is a **button inside an on-page
  panel**, which does not grant `activeTab`.

Hence the broad declaration. In practice:

- The content script is injected **only** into `https://*.tradingview.com/*`.
  No other site is touched.
- No page content is ever sent anywhere.
- The extension does not read your passwords, forms, cookies, or any unrelated data.

### 5. Third parties

No data is shared, sold, or transferred to any third party, because no data ever
leaves your machine.

### 6. Children

The extension is not directed at children and collects no age-related information.

### 7. Changes

If a future version changes how data is handled, the change will be stated in the
release notes and this document will be updated.

### 8. Contact

Reach the developer through the support channel on the store listing page.
